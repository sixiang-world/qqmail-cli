# Muse Agent 无头 Linux 实测报告（2026-11-27）

来源：用户提供的 Muse Agent 对 qqmail-cli v0.6.0 的当日实测记录。本文为脱敏整理版；时间均为北京时间。观察结果来自原报告，未由维护者独立复测；网络故障根因尚未完全确定。

## 已验证的核心链路

截至 16:01，IMAP auth login 成功（约 3 秒，verified=true），凭证写入系统密钥环；auth status 显示 configured=true、credential_present=true、custom_server=false。通过一次 envelope list 和一次 message show 读取最近 5 封邮件；用户授权配置收件人白名单和 auto_send 后，send --execute 成功（约 3.3 秒），目标邮箱收到邮件。JSON 输出及现有 dry-run、白名单和确认门禁表现符合预期。

网络时通时断是观察事实；不能据此排除全部 DNS、代理、路由或服务端因素，也不能确认触发腾讯限流。不要永久硬编码服务端 IP，不要关闭证书校验或绕过平台网络授权。

## 安全与范围

保留原有 readonly、allowlist、人工确认、审计、凭证脱敏和不确定投递保护。自动发送只在明确用户授权后启用。云端 VM 的网络与依赖持久性属于环境因素，CLI 只能改善诊断及合规容错。跨 VM 凭证自动解锁与恢复尚未验证。

个人邮箱、具体出口基础设施及非必要网络细节已省略；未包含授权码或真实邮件正文。任务拆分及验收条件见 [开发路线图](../roadmap.md)。
