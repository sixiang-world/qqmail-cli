# 自动发送与草稿文件实现计划（Implementation Plan）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现 spec 的五项能力——Content-ID 域名改发件人域、确认 token 大小写不敏感、`--draft-file`、autosend（auto_send/send_blacklist/daily_auto_limit + 本地计数器）、配套文档。

**Architecture:** 全部改动集中在发送完成路径（`internal/cli/send.go` 的 `runDraft`）与配置层（`internal/account/config.go` 的 Account/Named），不新增命令、不新增输出字段、不动 allowlist 之外的任何门禁。autosend 判定器（`autoSendEligible`）插在 allowlist 校验之后、`confirmToken` 之前；每日计数器是配置目录下的本地 JSON 状态文件（safeio 原子写），不进审计不进输出。

**Tech Stack:** Go 1.25、github.com/pelletier/go-toml/v2（既有依赖，草稿文件解析）、internal/safeio（原子写，既有）、cobra。

**Spec:** docs/superpowers/specs/2026-10-07-autosend-design.md（已含 F4 修正案——Message-ID 本就合规，指纹仅 Content-ID）

## Global Constraints

- 输出形状零变化：不加 "auto" 标记、不加任何新 JSON 字段（spec §0 硬约束 1）。
- allowlist 未命中 → policy_denied 不变；readonly 总闸永远优先于 autosend（spec 不变量 1/2）。
- `daily_auto_limit` 缺省或 ≤0 一律按 50 处理（spec §3）。
- 全仓 `qqmail-cli.local` 字符串清零（spec 历史/计划文档除外）。
- 每任务收尾 `go test ./...` + `go vet ./...` 全绿；守卫（readonly/AST/反射/协议/golden/契约）不松动。
- 草稿文件路径按 CWD 解析（与 --body-file/--attach 现语义一致）。

```go
// autoSendEligible decides whether this send may complete without the TTY
// confirmation: only when auto_send is on, every recipient is outside the
// blacklist, and the daily counter is under the limit. Blacklisted
// recipients fall back to the interactive gate; allowlist misses and
// readonly are refused upstream.
func autoSendEligible(named account.Named, recipients []string, now time.Time) (bool, error) {
	if !named.AutoSend {
		return false, nil
	}
	bl := blackSet(named.SendBlacklist)
	for _, r := range recipients {
		if bl[strings.ToLower(strings.TrimSpace(r))] {
			return false, nil
		}
	}
	count := readAutoSendCount(now) // 状态文件：配置目录/qqmail-cli/autosend-state.json {"date":"2006-01-02","count":N}
	limit := named.DailyAutoLimit
	if limit <= 0 {
		limit = 50
	}
	if count >= limit {
		return false, &errmap.Error{Kind: errmap.PolicyDenied, Message: "已达今日自动发送上限", Suggestion: fmt.Sprintf("每日自动发送上限 %d 封；明日自动重置，或人工在交互终端执行（不受此限）", limit)}
	}
	return true, nil
}

}
```
