# v0.4 功能补全批次实现计划（Implementation Plan）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按 spec 补全 qqmail-cli 的十个可实现功能：服务端全文搜索、envelope 过滤器、mark-unread、星标管理、单封 trash、folder create/rename、reply --reply-all、HTML 正文、--save-draft、契约收尾。

**Architecture:** 全部新写动词落在 `internal/imapx/mutate.go` 单文件（`StoreFlags`/`AppendDraft`/`CreateFolder`/`RenameFolder` 四个新原语），经 `internal/policy` 层到达命令层，复用既有 dry-run→`--execute`→TTY 确认→审计管线；发送面在 `internal/sendmail` 扩展 MIME 构建但不放松任何门禁。四个波次独立可发布，按任务顺序执行即按依赖序。

**Tech Stack:** Go 1.25（`CGO_ENABLED=0`）、go-imap v2（`github.com/emersion/go-imap/v2`，只允许 `internal/imapx` 导入）、cobra、SQLite（现代cgo-free 驱动，既有）、内嵌 JSON Schema。

**Spec:** `docs/superpowers/specs/2026-10-06-v0.4-feature-completion-design.md`（本计划逐节论证自该 spec；执行者两份都要读）

## Global Constraints

- JSON 输出 `schema_version: "1"`，字段只增不删；新命令全部内嵌/登记 schema 与 `agent-info`。
- go-imap 写方法只允许出现在 `internal/imapx/mutate.go`（`internal/readonlyaudit/audit_test.go` 的 AST 禁用表在 CI 强制；新原语恰好落在禁用表白名单文件内，无需改该测试）。
- `Reader` 接口方法面零变化：`internal/imapx/readonly_test.go` 的反射白名单必须保持绿、不修改。
- 永远不出现 EXPUNGE/CLOSE 下发路径；协议线路断言测试保持绿。
- `QQMAIL_CLI_READONLY=1` 锁死本批全部新写命令；未知取值按只读处理（既有语义）。
- 发送三门禁零放松：`send_allowlist` 全员命中、dry-run 默认、真实 TTY 键入 `SEND`；每次调用单封、收件人 ≤10、附件合计 ≤20 MiB、正文源码 ≤1 MiB。
- 全部新写动作进内容无关审计 JSONL（不记录地址/主题/正文/附件名/搜索词）。
- 读路径永远 `EXAMINE` + `BODY.PEEK`；新增只读命令不消费 `\Seen`。
- 测试夹具一律合成；仓库不接收真实邮件样本。方言探测是唯一触真实服务器的活动，只读探测，产出进 `docs/compat/`。
- 每个任务收尾：`go test ./...`、`go vet ./...`、`golangci-lint run` 全绿后提交。
- 前置条件：工作区未提交的 2026-10-05 审计修复轮先落地（单独提交），本计划所有任务基于其上的干净树。若 go-imap v2 个别方法签名与下列代码有出入，以同文件既有调用形态（`SetSeen`/`MoveUID`/`CopyMarkDeletedUID`）校正，不改变行为语义。

	defer cancel()
	reader, named, err := rt.connect(ctx)
	if err != nil {
		return err
	}
	defer func() { _ = reader.Logout(context.Background()) }()
	_, uidValidity, err := reader.Examine(ctx, rt.Folder)
	if err != nil {
		return err
	}
	uids, err := reader.Search(ctx, imapx.SearchFilter{Text: query, Limit: searchLimit(cmd)})
	if err != nil {

	}
	envelopes, err := reader.FetchEnvelopes(ctx, rt.Folder, uidValidity, uids)
	if err != nil {
		return err
	}
	return writeSearchResult(rt, named, envelopes) // 复用 envelope list 的输出装配；command="search"，meta.search_mode 按 ServerSearchField
}

```go
// SetFlags adds or removes flags on one message. Exactly one of add/remove
// must be non-empty; policy layer owns the \Flagged/\Seen vocabulary.
func (c *Client) SetFlags(ctx context.Context, id mailmodel.MsgID, add, remove []string) error {
	if (len(add) == 0) == (len(remove) == 0) {
		return &errmap.Error{Kind: errmap.Usage, Message: "SetFlags 要求 add/remove 恰一非空"}
	}
	if err := c.selectWritable(ctx, id); err != nil {
		return err
	}
	if err := c.setDeadline(ctx); err != nil {
		return err
	}
	stop := c.watchdog(ctx)
	defer stop()
	op, flags := imap.StoreFlagsAdd, toFlagList(add)
	if len(remove) > 0 {
		op, flags = imap.StoreFlagsRemove, toFlagList(remove)
	}
	command := c.raw.Store(imap.UIDSetNum(imap.UID(id.UID)), &imap.StoreFlags{Op: op, Silent: true, Flags: flags}, nil)
	return command.Close()
}

func toFlagList(names []string) []imap.Flag {
	out := make([]imap.Flag, 0, len(names))
	for _, n := range names {
		out = append(out, imap.Flag(n))
	}
	return out
}
```

同时在 `Mutator` 接口追加 `SetFlags(context.Context, mailmodel.MsgID, []string, []string) error`。

```go
// mergeReplyAll expands a reply into a reply-all recipient set. Self is
// dropped everywhere; dedupe is case-insensitive; original order is kept.
// The original Bcc never reaches this function — it is not part of the
// received envelope, and the test suite asserts that invariant.
func mergeReplyAll(self string, replyTo, origTo, origCc []mail.Address) (to, cc []mail.Address) {
	key := func(a mail.Address) string { return strings.ToLower(strings.TrimSpace(a.Address)) }
	selfKey := strings.ToLower(strings.TrimSpace(self))
	seen := map[string]bool{}
	add := func(list []mail.Address, into *[]mail.Address) {
		for _, a := range list {
			k := key(a)
			if a.Address == "" || k == selfKey || seen[k] {
				continue
			}
			seen[k] = true
			*into = append(*into, a)
		}
	}
	add(replyTo, &to)
	add(origTo, &to)
	add(origCc, &cc)
	return to, cc
}
```

```go
// DerivePlainText renders a deterministic plain-text fallback for an HTML
// body: block tags become newlines, script/style blocks are dropped, tags
// are stripped, entities decoded, whitespace collapsed. It is what the
// recipient's text-mode client will roughly see and what the human confirms.
func DerivePlainText(html string) string {
	s := regexp.MustCompile(`(?is)<(script|style)\b.*?</\1>`).ReplaceAllString(html, "")
	s = regexp.MustCompile(`(?i)<(br|/p|/div|/li|/tr|/h[1-6])\b[^>]*>`).ReplaceAllString(s, "\n")
	s = regexp.MustCompile(`(?s)<[^>]*>`).ReplaceAllString(s, "")
	s = html.UnescapeString(s)
	s = strings.Join(strings.Fields(s), " ")
	lines := strings.Split(s, "\n")
	for i := range lines {
		lines[i] = strings.TrimSpace(lines[i])
	}
	return strings.TrimSpace(strings.Join(lines, "\n"))
}
```

func DraftsFolder(ctx context.Context, reader imapx.Reader) (string, error) {
	folders, err := reader.ListFolders(ctx)
	if err != nil {
		return "", err
	}
	for _, f := range folders {
		for _, attribute := range f.Attributes {
			if strings.EqualFold(attribute, `\Drafts`) {
				return f.Name, nil
			}
		}
	}
	for _, candidate := range []string{"Drafts", "草稿箱"} { // 候选名以 Task 0 探测定案为准
		for _, f := range folders {
			if strings.EqualFold(f.Name, candidate) {
				return f.Name, nil
			}
		}
	}
	return "", fmt.Errorf("server drafts folder could not be identified")
}
