# v0.4 功能补全批次实现计划（Implementation Plan）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按 spec 补全 qqmail-cli 的十二个可实现功能：服务端全文搜索、envelope 过滤器（--before/--to）、内嵌图（CID 部件）入附件清单、mark-unread、星标管理、单封 trash、folder create/rename、reply --reply-all、HTML 正文、内嵌图发送（multipart/related）、--save-draft、契约收尾。

**Architecture:** 全部新写动词落在 `internal/imapx/mutate.go` 单文件（`StoreFlags`/`AppendDraft`/`CreateFolder`/`RenameFolder` 四个新原语），经 `internal/policy` 层到达命令层，复用既有 dry-run→`--execute`→TTY 确认→审计管线；发送面在 `internal/sendmail` 扩展 MIME 构建（multipart/alternative + multipart/related）但不放松任何门禁；读取面在 `internal/mimeparse` 把 inline 非文本部件纳入附件清单。四个波次独立可发布，按任务顺序执行即按依赖序。

**Tech Stack:** Go 1.25（`CGO_ENABLED=0`）、go-imap v2.0.0-beta.8（`github.com/emersion/go-imap/v2`，只允许 `internal/imapx` 导入）、go-message v0.18.2（`github.com/emersion/go-message`）、cobra、SQLite（既有驱动）、内嵌 JSON Schema。

**Spec:** `docs/superpowers/specs/2026-10-06-v0.4-feature-completion-design.md`（本计划逐节论证自该 spec；执行者两份都要读）

## Global Constraints

- JSON 输出 `schema_version: "1"`，字段只增不删；新命令全部内嵌/登记 schema 与 `agent-info`。
- go-imap 写方法只允许出现在 `internal/imapx/mutate.go`（`internal/readonlyaudit/audit_test.go` 的 go-imap import 边界扫描在 CI 强制）；同时每新增一个 Mutator 方法，必须把方法名加入同文件 `TestMutationBoundaryCanOnlyBeCalledByPolicy` 的 `mutationMethods` 白名单（该测试强制新原语仅 policy 层可调）。
- `Reader` 接口方法面零变化：`internal/imapx/readonly_test.go` 的反射白名单测试函数与白名单清单不改、必须保持绿（新增独立测试文件不受此限）。
- 永远不出现 EXPUNGE/CLOSE 下发路径；既有协议断言保持绿。
- `QQMAIL_CLI_READONLY=1` 锁死本批全部新写命令；未知取值按只读处理（既有语义）。readonly 阻断矩阵在 `internal/cli/cli_test.go` 的 `TestReadonlyEnvironmentBlocksEveryMutatingCommandBeforeDial`，新增 mutate 命令必须在此登记；**readonly + 无 `--execute` 走 dry-run 正常退出 0，readonly + `--execute` 才是退出码 50**（既有矩阵语义）。
- 新增叶命令必须同步登记 `internal/cli/agent.go` 的 `commandCatalog()`，否则 `TestCommandTreeMatchesDeclaredRiskCatalog`（cli_test.go）失败。
- 发送三门禁零放松：`send_allowlist` 全员命中、dry-run 默认、真实 TTY 键入 `SEND`；每次调用单封、收件人 ≤10、附件与内嵌图合计 ≤20 MiB、正文源码 ≤1 MiB。
- 全部新写动作进内容无关审计 JSONL（不记录地址/主题/正文/附件名/搜索词）。
- 读路径永远 `EXAMINE` + `BODY.PEEK`；新增只读命令不消费 `\Seen`。
- 测试夹具一律合成；仓库不接收真实邮件样本。方言探测是唯一触真实服务器的活动，只读探测，产出进 `docs/compat/`。
- **线路断言 fixture 约定**：plan 中 `newFixture`/`newWritableFixture`/`LastSearchLine`/`LastStoreLine`/`LastAppend`/`LastCreateLine`/`LastRenameLine`/`newPolicyFixture` 等是**新建记录型 fake 的接口约定**（照 `internal/imapx/dialect_test.go` 的手写 bufio 逐行服务风格，或改用 `integration_test.go` 的 imapmemserver 行为断言）——仓库现无此类通用 fixture，各任务新建并落在新测试文件中；**不是**复用 readonly_test.go。行为级断言（解析结果、命令输出）照各文件既有风格。
- 每个任务收尾：`go test ./...`、`go vet ./...`、`golangci-lint run` 全绿后提交。
- 前置条件：2026-10-05 审计修复轮已落地（提交 6993f49）。go-imap 个别 API 与本计划代码有出入时，以 module cache 中 go-imap v2.0.0-beta.8 的真实签名为准校正（本计划已按 beta.8 校正：`StoreFlagsDel`、`Append(mailbox, size, options)` + `Write`/`Close`/`Wait`、`Rename(old, new, options)`）。

```go
func WrapSearchReject(err error) error {
	var imapErr *imap.Error
	if errors.As(err, &imapErr) && (imapErr.Type == imap.StatusResponseTypeNo || imapErr.Type == imap.StatusResponseTypeBad) {
		return &errmap.Error{Kind: errmap.PolicyDenied,
			Message:    "服务器拒绝了这个搜索条件（见 docs/compat/qq-20261006.md）",
			Suggestion: "改用 --from/--subject 过滤，或 qqmail-cli sync 后 search --local", Cause: err}
	}
	return err
}
```

```go
// SetFlags adds or removes flags on one message. Exactly one of add/remove
// must be non-empty; policy layer owns the \Flagged/\Seen vocabulary.
func (c *Client) SetFlags(ctx context.Context, id mailmodel.MsgID, add, remove []string) error {
	if (len(add) == 0) == (len(remove) == 0) {
		return &errmap.Error{Kind: errmap.Usage, Message: "SetFlags 要求 add/remove 恰一非空"}
	}
	if err := c.selectWritable(ctx, id); err != nil {
		return err
	}
	if err := c.setDeadline(ctx); err != nil {
		return err
	}
	stop := c.watchdog(ctx)
	defer stop()
	op, flags := imap.StoreFlagsAdd, toFlagList(add)
	if len(remove) > 0 {
		op, flags = imap.StoreFlagsDel, toFlagList(remove) // beta.8 常量名是 StoreFlagsDel
	}
	command := c.raw.Store(imap.UIDSetNum(imap.UID(id.UID)), &imap.StoreFlags{Op: op, Silent: true, Flags: flags}, nil)
	return command.Close()
}

func toFlagList(names []string) []imap.Flag {
	out := make([]imap.Flag, 0, len(names))
	for _, n := range names {
		out = append(out, imap.Flag(n))
	}
	return out
}
```

```go
// mergeReplyAll expands a reply into a reply-all recipient set. Self is
// dropped everywhere; dedupe is case-insensitive; original order is kept.
// The original Bcc never reaches this function — it is not part of the
// received envelope, and the test suite asserts that invariant.
func mergeReplyAll(self string, replyTo, origTo, origCc []mail.Address) (to, cc []mail.Address) {
	key := func(a mail.Address) string { return strings.ToLower(strings.TrimSpace(a.Address)) }
	selfKey := strings.ToLower(strings.TrimSpace(self))
	seen := map[string]bool{}
	add := func(list []mail.Address, into *[]mail.Address) {
		for _, a := range list {
			k := key(a)
			if a.Address == "" || k == selfKey || seen[k] {
				continue
			}
			seen[k] = true
			*into = append(*into, a)
		}
	}
	add(replyTo, &to)
	add(origTo, &to)
	add(origCc, &cc)
	return to, cc
}
```

```go
// DerivePlainText renders a deterministic plain-text fallback for an HTML
// body: block tags become newlines, script/style blocks are dropped, tags
// are stripped, entities decoded, whitespace collapsed. It is what the
// recipient's text-mode client will roughly see and what the human confirms.
func DerivePlainText(html string) string {
	s := regexp.MustCompile(`(?is)<(script|style)\b.*?</\1>`).ReplaceAllString(html, "")
	s = regexp.MustCompile(`(?i)<(br|/p|/div|/li|/tr|/h[1-6])\b[^>]*>`).ReplaceAllString(s, "\n")
	s = regexp.MustCompile(`(?s)<[^>]*>`).ReplaceAllString(s, "")
	s = html.UnescapeString(s)
	s = strings.Join(strings.Fields(s), " ")
	lines := strings.Split(s, "\n")
	for i := range lines {
		lines[i] = strings.TrimSpace(lines[i])
	}
	return strings.TrimSpace(strings.Join(lines, "\n"))
}
```
